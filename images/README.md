# Billeder til felterne

Læg dine billeder i denne mappe. Filnavnet bestemmer hvilket felt de dukker op på, når det krydses af — de vises automatisk, ingen kodeændring nødvendig.

Understøttede filtyper: `.jpg`, `.jpeg` eller `.png` (prøves i den rækkefølge).
